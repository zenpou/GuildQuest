# ミレイ（Mirei）設計図

## 基本設定

- 年齢：24歳。
- 外見：濃紺髪のローポニー、丸眼鏡、アイボリーのブラウス、青緑のベスト。
- 役割：ギルド受付・記録・解放条件の案内役。冒険者の派遣隊には参加しない。
- 経歴：大手ギルドで3年受付をしていた。才能のある人を見逃す組織に疑問を持ち、ユウトの噂を聞いて酒場を訪ね、能力の限界も聞いたうえで共同のギルド運営を提案する。
- 実装状況：`characters.json` の固定冒険者ではなく、Coreの給与・戦闘・派遣数値は持たない。`story-prologue.json` と `campaign-story.json` の台詞、UIの章案内、設定資料画像、現行3ポーズに登場する。

## 画像で固定された外見

- シルエット：細身で姿勢がよく、濃紺のローポニーと丸眼鏡の輪郭を持つ。記録帳を胸元に抱える。
- 色：アイボリーのブラウス、青緑のベスト、濃紺の髪。主人公の濃紺と競合しないようベストを青緑に寄せる。
- 小物：受付帳と羽根ペン。ギルド印、鍵束、依頼書を留めるクリップは場面小物として追加できるが、現行資料の固定小物は記録帳とペンである。
- 三面図：正面・側面・背面の丸眼鏡、ローポニーの結び目、ベストの刺繍と腰の小袋を `reference.webp` に合わせる。

## 口調と避ける表現

明るく丁寧で、説明が早い。有能さを自慢せず、ユウトの発言を善意に深読みする。

例：

- 「まず『冒険者』でアルドを狩人に転職。そのあと『派遣』で薬草採取を選んでください」
- 「研修期間は終了です。今後は評判に応じて坑道と遺跡の依頼が開きます」
- 「最初から帰り道まで見通していたんですね……！」

避ける表現：冷たい事務員、主人公の代わりに全判断をする万能秘書、仲間の怪我を数字だけで処理する言い方。誤解はするが、記録と安全確認は正確に行う。

## 欲求と弱点

- 欲求：適性のある人が見逃されず、記録が人を守るギルドを作る。
- 弱点：ユウトを過大評価し、説明の途中で「深い意図」を補ってしまう。期待を支えるために自分の疲れを後回しにする。

## アーク

- 始点：酒場でユウトと運営を相談し、市の小規模ギルド支援制度を使って仮認可と事務所を手配する。手続き後の運転資金600Gと、開業後5日間の日額90Gの補助を帳簿に残す。
- 転機：第一章で転職と初回派遣を手順にし、第二章で募集・施設の解放を説明する。帰還欄、給与、負傷、章の記録を増やすたび、ギルドが制度になる。
- 終点：討伐成功時は水門と帰還を確認する受付として、ユウトの見えない努力を仲間へ伝える。期限超過時は継続審査を「落第」ではなく、今日の仕事へ接続する。

## ゲーム数値・役割との接続

ミレイには現在 `Adventurer` 数値がない。募集、派遣、施設、財務のCore判定は担当せず、`tutorialObjective` のタブ移動、章の台詞、UIの説明を担当する。`campaign-story.json` の `first_desk`、`first_return`、`policy`、`recruit`、`facilities`、`charter`、`ruins`、`eve`、両終章に登場するため、章間の連続性を保つ記録係として扱う。

## 関係性

- ユウト：能力を見抜く先生だと信じて先に仕事を進める。ユウトの「普通に読んだだけ」と彼女の深読みがコメディの軸。
- アルド：転職手続きを支える。弓の成功を制度として残す。
- ミナ：体調と薬草の記録を共有する。
- リナ：遅刻や給与を帳簿に残すが、孤児院への送金を知った後は記録の意味を変える。
- ブルーノ：給与と負傷の現実を確認する相手。
- ガロ：空き事務所と酒場の境界をつなぐ街の窓口。

## 現行ポーズと将来候補

### 現行ゲーム内ポーズ

`neutral` は受付・手順説明、`thoughtful` は記録や期限を確認する場面、`happy` は帰還・討伐確認を伝える場面に使う。

### 将来候補（現行アセット外）

依頼を説明する笑顔、記録欄の不足に気づく真剣顔、ユウトを誤解して感動する顔、負傷者を見た心配、期限を確認する緊張、継続審査を伝える安堵、討伐確認の喜び。受付帳と眼鏡が顔や台詞を隠さないバストアップを追加する場合も、設定資料の位置関係を維持する。
