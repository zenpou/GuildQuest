# ミナ（Mina）設計図

## 基本設定

- 年齢：17歳。
- 外見：茶髪の三つ編み、セージ緑の衣装、薬草袋。薬草を持つ手と、仲間を確かめる視線を記号にする。
- 初期職：術師（`mage`）。回復魔法と採取を担当する。
- 性格：仲間思い（`caring`）。負傷者をかばい、関係値が上がりやすい。
- 実装状況：固定メンバー、初期能力、薬草博士の既判明特性、個人イベント `mina_herb` / `mina_worry`、章 `first_desk` / `first_return` / `facilities` / `mina`、設定資料画像、現行3ポーズは収録済み。

`reference.webp` が外見の正本で、現行ポーズは茶色の三つ編み、花飾り、セージ緑の衣装、生成りのケープ、薬草袋を共有する。現在のゲーム内演出はこの3ポーズを使い、別表情・別衣装は将来候補として扱う。

## 画像で固定された外見

- シルエット：小柄で、花飾りのある三つ編みが肩から前へ流れる。腰の薬草袋と生成りのケープで識別する。
- 色：セージ緑の衣装、生成りのケープ、柔らかな茶色の髪と革小物。魔法演出は白緑で、攻撃魔法の強い赤や紫と区別する。
- 小物：花束、薬草袋、革の小瓶とブーツ。乾燥束、包帯、小さな茶器は場面小物として追加できるが、現行資料の固定小物ではない。
- 三面図：正面・側面・背面の三つ編み、花飾り、ケープの縁、薬草袋の位置を `reference.webp` に合わせる。

## 口調と避ける表現

明るく丁寧で、相手の状態を先に気にする。心配の台詞が続いても、相手を責めない。

例：

- 「薬草採取なら私も行きます。道を見つける人と、草を見分ける人。二人でできる仕事ですね」
- 「みんな無事？ 痛いところはない？」
- 「必要だから、ずっと働かなきゃいけないと思ってました。今日は私も座ります」

避ける表現：いつでも笑顔で疲れを見せない、回復役だから自分の負傷を無視する、仲間を子ども扱いする、薬草知識を万能医療として扱う。

## 欲求と弱点

- 欲求：仲間の痛みを減らし、アルドと一緒に安心して帰れる場所を作る。
- 弱点：役に立ち続けなければ必要とされないと思い、自分の休息・負傷・空腹を後回しにする。

## アーク

- 始点：薬草師の孫として採取と回復魔法に長け、アルドを心配して村から出てくる。初回派遣では薬草採取の成功を支える。
- 転機：仲間の負傷を見舞う `mina_worry`、自分の派遣回数が増える `mina_herb`、施設章で休める場所の必要を認める。
- 終点：薬を渡す人であると同時に、薬草茶を飲んで休む人になる。討伐前は、行けるかどうかを自分の体調として口にできる。

## ゲーム数値・役割との接続

実装初期値は Lv1、HP52、攻撃5、守備5、魔力14、素早さ7、器用さ9、探索8、採取16、成長率1.30。適性は剣士15、狩人35、術師88。性格は `caring`、初期忠誠度70、`herbalist` は既判明。術師のスキルは `fire`（必中、倍率1.6、CT3、守備無視0.5）、回復「癒しの光」は最大HPの30%相当。薬草博士は採取成功率と量に影響するため、day1の `q_herb` と物語が直結する。

個人イベント `mina_herb` は派遣2回、`mina_worry` は他の仲間が負傷中に発火する。章 `facilities` は「治す人にも休む場所が必要」という施設選択へつなげる。

## 関係性

- アルド：初期関係値+28。幼なじみとして、剣の三年を否定せず弓の一歩を支える。
- リナ：初期関係値+6。ミナが座らないとリナも休めないという、日常の軽い支え合いがある。
- ブルーノ：固定初期値は未定義。負傷と年齢を気にかけるが、ブルーノの自尊心を傷つけない距離を取る。
- ユウト：ユウトの安全第一を、仲間の体調を言葉にする役として具体化する。
- ミレイ：薬草袋や施設費を記録する相手。ガロ：薬草茶を出せる酒場の店主として、休憩場所を共有する。

## 現行ポーズと将来候補

### 現行ゲーム内ポーズ

`neutral` は薬草採取・通常会話、`thoughtful` は負傷や疲労を心配する場面、`happy` は仲間と休む場面に使う。

### 将来候補（現行アセット外）

採取中の集中、回復魔法、負傷者を心配する顔、自分の疲れを隠す顔、初めて椅子に座る安堵、薬草茶を差し出す笑顔、最終出発前の静かな決意。追加する場合も、袋の大きさ、三つ編み、花飾り、ケープの縁は設定資料から変えない。
