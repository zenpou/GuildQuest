# リナ（Lina）設計図

## 基本設定

- 年齢：16歳。
- 外見：銅髪のボブ、紺色のチュニック、錆色のスカーフ。軽い身のこなしとスカーフの端で画面上の識別性を作る。
- 初期職：狩人（`ranger`）。探索と戦利品の判断を担当する。
- 性格：強欲（`greedy`）。宝箱と高報酬に目がないが、稼いだ金の一部を孤児院へ送る。
- 実装状況：固定メンバー、初期能力、個人イベント `lina_lost` / `lina_money`、章 `mine` / `bruno`、設定資料画像、現行3ポーズは収録済み。`directionless` と `lucky` は未判明特性として開始する。

## 現行の設定資料画像

`guild-dawn.webp` で確定したリナの外見を、個別の設定資料に固定している。今後のスチル・立ち絵はこの資料を基準にする。

- [設定資料（正面・側面・背面・表情・小物）](../../public/art/characters/lina/reference.webp)
- 現行ポーズ：[neutral](../../public/art/characters/lina/neutral.webp) ・ [thoughtful](../../public/art/characters/lina/thoughtful.webp) ・ [happy](../../public/art/characters/lina/happy.webp)

`reference.webp` が外見の正本で、現行ポーズは銅色のボブ、紺のチュニック、錆色のスカーフ、革の小袋を共有する。現在のゲーム内演出はこの3ポーズを使い、別表情・別衣装は将来候補として扱う。

## 画像で固定された外見

- シルエット：小柄で前のめり、短いボブと長めのスカーフが動く。腰の小袋と軽装で、ブルーノの重い輪郭と対比する。
- 色：紺のチュニック、錆色のスカーフ、銅髪。コインの金属色はアクセントにとどめ、派手な宝飾品にはしない。
- 小物：肩掛けの革ベルト、腰の小袋、簡素な金具。短弓、地図の切れ端、赤い目印布は物語上の小道具として追加できるが、現行資料の固定小物ではない。
- 三面図：正面・側面・背面のスカーフの結び、ボブの輪郭、小袋、チュニックの裾を `reference.webp` に合わせる。

## 口調と避ける表現

短く、早口で、金額や得失をすぐ口にする。強がりの直後に小さな本音が漏れる。

例：

- 「外に人が並んでる。面接料、とっていい？」
- 「お金の匂いがするところにしか来ないから。宝箱の依頼、ある？」
- 「あたし、帰り道はよく間違えるよ。だから目印、みんなで決めて」

避ける表現：金だけで人を裏切る、孤児院への送金を早い段階から自慢する、方向音痴を知能の低さとして扱う、年齢に不釣り合いな大人の説教口調。

## 欲求と弱点

- 欲求：稼いで孤児院へ送り、二度と誰かに見捨てられない生活を作る。自分の居場所も欲しい。
- 弱点：目先の報酬と宝箱に引っ張られ、危険や帰り道を軽く見る。探索能力が高いのに方向を間違えることを本人も恥じている。

## アーク

- 始点：孤児院育ちの元スリ見習い。金勘定と目端は利くが、ギルドへ来る道に迷って遅れる。
- 転機：派遣3回で方向音痴が話題になり、5日目以降の `lina_money` で稼ぎの半分を孤児院へ送っていることが分かる。坑道では、過去に逃げた水路を誰かを帰すために使うか選ぶ。
- 終点：報酬を取りに行く人から、帰還路の目印を皆で決める人へ変わる。看板を塗り直す約束は、居場所を自分で整える行為でもある。

## ゲーム数値・役割との接続

実装初期値は Lv1、HP50、攻撃8、守備4、魔力6、素早さ12、器用さ14、探索14、採取10、成長率0.95。適性は剣士30、狩人80、術師45。性格は `greedy`、初期忠誠度55。特性 `directionless` と `lucky` は未判明。狩人の探索・採取補正と、強欲の宝箱・戦利品への影響が、物語上の長所と弱点をそのままゲームにする。

`lina_lost` は派遣3回で発生し、方向音痴を判明させる。`lina_money` は5日目以降で、忠誠度とブルーノとの関係値を上げる。坑道依頼成功後に `mine` が開き、リナの過去の道がチームの資産になる。

## 関係性

- ミナ：初期関係値+6。ミナに休ませてもらう側だが、ミナが休むきっかけも作る。
- ブルーノ：初期関係値-14。武勇伝と年齢差を茶化すが、`lina_money` で金を孤児院へ送る事情を知られる。
- アルド：固定初期値は未定義。慎重なアルドを「考えすぎ」とからかい、探索と戦闘の判断を補い合う。
- ユウト：数字で見えない送金理由をユウトに発見させる。リナはユウトの深読みを一番軽く受け流す。
- ミレイ：遅刻や迷子を記録される相手。ガロ：孤児院や街の噂を耳にする生活情報の入口。

## 現行ポーズと将来候補

### 現行ゲーム内ポーズ

`neutral` は募集・通常会話、`thoughtful` は迷子や過去を話す場面、`happy` は報酬や帰還を喜ぶ場面に使う。

### 将来候補（現行アセット外）

宝箱を見つけた笑顔、報酬を数える真剣顔、迷子をごまかす焦り、送金を知られた照れ、坑道で過去を思い出す硬い顔、赤い目印布を結ぶ集中、帰還後の看板を塗る満足。スカーフが風や移動で顔を隠さないよう、結び位置は設定資料から変えない。
