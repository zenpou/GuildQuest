# アルド（Aldo）設計図

## 基本設定

- 年齢：19歳。
- 外見：茶髪、琥珀眼、オリーブ色のマント。狩人へ転職した後は弓と矢筒を主シルエットにする。
- 初期職：剣士（`fighter`）。物語上の転機で狩人（`ranger`）へ転職する。
- 性格：慎重（`cautious`）。危険を避け、罠を警戒し、早めの撤退を口にする。
- 実装状況：固定メンバー、初期能力、職業適性、`keen` 特性、個人イベント `aldo_bow` / `aldo_caution`、章 `first_desk` / `first_return` / `aldo_trust`、設定資料画像、現行3ポーズは収録済み。

## 現行の設定資料画像

`guild-dawn.webp` で確定したアルドの外見を、個別の設定資料に固定している。今後のスチル・立ち絵はこの資料を基準にする。

- [設定資料（正面・側面・背面・表情・小物）](../../public/art/characters/aldo/reference.webp)
- 現行ポーズ：[neutral](../../public/art/characters/aldo/neutral.webp) ・ [thoughtful](../../public/art/characters/aldo/thoughtful.webp) ・ [happy](../../public/art/characters/aldo/happy.webp)

`reference.webp` が外見の正本で、現行ポーズは同じ髪型、オリーブ色のフード付きマント、弓と矢筒、革装備を共有する。現在のゲーム内演出はこの3ポーズを使い、別表情・別衣装は将来候補として扱う。

## 画像で固定された外見

- シルエット：細身で少し前傾。弓を横に背負い、矢筒の直線で他の4人と区別する。剣士時は腰の剣が残るが、狩人への転職後は弓が画面の主線になる。
- 色：オリーブのマント、土色の革、琥珀の目。森の背景に埋もれないよう、マントの縁に薄い黄土色を置く。
- 小物：弓、矢筒、革のベルトと手袋。現在の資料にない剣の鞘は固定設定に追加しない。三年間の剣の稽古は台詞と職歴で表現する。
- 三面図：正面・側面・背面のマント、弦、矢筒、革装備の位置を `reference.webp` に合わせる。弓を構えたときに顔が隠れない。

## 口調と避ける表現

序章では剣士としての仕事に困る愚痴を主人公が聞き、会話と自己紹介を経て弓を試す。弓を借りる前は弓・矢筒付きの立ち絵を出さず、発話時の顔のみを表示する。練習場で借りた後から立ち絵を使う。

一人称は「僕」。声量は控えめで、考えてから話す。「……」を使いすぎず、怖さを認めた上で次の行動を選ぶ。

例：

- 「剣の稽古は三年。でも、弓を借りた日は手が迷わなかったんです」
- 「僕が引き返そうと言っても、臆病だと思われませんか」
- 「適性があるからって、外さないわけじゃない。だから、外した日の報告書も残します」

避ける表現：転職した瞬間に自信満々になる、剣の三年を無駄と断定する、慎重さを単なる臆病として笑いにする、弓の才能だけで仲間を見下す。

## 欲求と弱点

- 欲求：自分に向いている場所で、仲間を危険に巻き込まず役に立ちたい。
- 弱点：過去に前へ出て仲間を負傷させた記憶があり、失敗の責任を先に想像してしまう。才能を見つけられた後は「才能があるのに失敗する」ことを恐れる。

## アーク

- 始点：田舎の道場を出て三年間剣を学んだが、剣士として芽が出ず、広場で座り込んでいる。
- 転機：ユウトに弓適性92、剣適性22を示され、借りた弓で的を射抜く。初回派遣で成功しても失敗しても、帰還報告を通じて「向いている」は成功の保証ではないと知る。
- 終点：弓使いとして自分の判断を報告でき、撤退を提案することを臆病と恥じなくなる。討伐成功時は全員の帰還を確認する声になり、期限超過時は次の出発を急がず準備を選ぶ。

## ゲーム数値・役割との接続

実装初期値は Lv1、HP66、攻撃9、守備9、魔力5、素早さ8、器用さ12、探索9、採取8、成長率1.15。適性は剣士22、狩人92、術師30。性格は `cautious`、初期忠誠度65、特性 `keen` は未判明。剣士は前衛、狩人は素早さ・探索・採取に寄るため、初日の転職がチュートリアルの中心になる。狩人のスキルは `snipe`（必中、倍率1.5、CT2）。

アルドを初回派遣に含めること、初回派遣までの日送りを制限すること、狩人適性の発見を `campaign.jobChanged` に記録することが、物語とCoreの接続点である。`aldo_bow` は狩人かつ2日目以降、`aldo_caution` は派遣4回で発火する。

## 関係性

- ミナ：初期関係値+28。幼なじみで、アルドの恐れを言葉にできる。
- ブルーノ：初期関係値+6。前衛の経験を尊敬しているが、先頭に立つ意味を教わるには時間がかかる。
- リナ：明示された固定初期値はない。探索と報酬の判断が異なり、派遣ログで関係を育てる余地を残す。
- ユウト：適性を見つけ、戻してもよいと言った人。恩を「才能を買われた」と誤解しないようにする。
- ミレイ：最初の転職と依頼を手順にしてくれる受付。ガロ：弓を射た場面の最初の観客。

## 現行ポーズと将来候補

### 現行ゲーム内ポーズ

`neutral` は受付・待機、`thoughtful` は適性や撤退を考える場面、`happy` は弓の成功・帰還・仲間との前進に使う。

### 将来候補（現行アセット外）

転職直後に弓を握る戸惑い、狙いを定める集中、外した直後の悔しさ、撤退を告げる不安、仲間をかばう決意、帰還確認の安堵、討伐後の静かな笑顔。追加する場合も、弓・矢筒・マントの位置は設定資料から変えない。
