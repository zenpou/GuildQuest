# ブルーノ（Bruno）設計図

## 基本設定

- 年齢：34歳。
- 外見：短い黒髪、顎髭、鋼の胸当て、ワイン色のマント。大柄な上半身と膝をかばう立ち方を両立させる。
- 初期職：剣士（`fighter`）。前衛、防御、撤退判断の基準を担う。
- 性格：自信家（`proud`）。成功すると調子に乗り、失敗時には責任の所在を気にする。
- 実装状況：固定メンバー、初期Lv2、初期能力、個人イベント `bruno_glory` / `bruno_knee`、章 `policy` / `facilities` / `charter` / `bruno`、設定資料画像、現行3ポーズは収録済み。

`reference.webp` が外見の正本で、現行ポーズは短い黒髪、顎髭、鋼の胸当て、ワイン色のマント、盾を共有する。現在のゲーム内演出はこの3ポーズを使い、別表情・別装備は将来候補として扱う。

## 画像で固定された外見

- シルエット：4人の中で最も大きい肩幅。鋼の胸当て、盾、ワイン色のマントで遠景でも判別する。
- 色：鈍い鋼色を主色、ワイン色を差し色、黒髪と茶革で落ち着かせる。ピカピカの英雄装備ではなく、手入れされた古参の装備。
- 小物：盾、剣、革のベルトと手袋。マントは坑道の赤い目印布へ転用できる長さとして台詞で扱う。
- 三面図：正面・側面・背面の胸当て、盾、マント、革装備の位置を `reference.webp` に合わせる。膝の状態はポーズと物語で表現し、装備を勝手に追加しない。

## 口調と避ける表現

低く落ち着いた口調。武勇伝を語るときは長くなるが、重要な場面では短く具体的に言う。

例：

- 「腕が立つ奴ほど、引く理由が必要なんだ」
- 「給料は出発しない日にも要る。待たせる余裕も、雇い主の腕のうちだ」
- 「若い人の代わりをしなくていい。若い人に、自分の代わりを育ててもらおう」

避ける表現：単なる頑固な老人、膝の負傷を笑いにする、若者を一方的に見下す、最後まで自分だけが前に立つ英雄像。

## 欲求と弱点

- 欲求：過去の名声ではなく、今いる仲間を生きて帰すことに価値を置き直す。
- 弱点：前に立てないことを「置いていかれた」と感じる。日給が高く、膝の負傷と疲労が経営上の重さになる。

## アーク

- 始点：かつて街で名の知れた剣士。膝を痛め、酒場で武勇伝を語りながらも前衛の腕は確か。
- 転機：3日目の `policy` で撤退の意味を教え、施設章で治療所と訓練所の優先順位を問い、派遣5回・Lv3で膝の限界を打ち明ける。12日目の `bruno` ではアルドの隣で教える側へ移る。
- 終点：先頭に立てない日も、装備の手入れ、若手の教育、撤退の判断で隊を守る。討伐成功時は「今日は訂正せんでもいい」と街の誤解を少しだけ受け入れる。

## ゲーム数値・役割との接続

実装初期値は Lv2、HP78、攻撃12、守備12、魔力4、素早さ5、器用さ7、探索6、採取5、成長率0.80。適性は剣士90、狩人25、術師10。性格は `proud`、初期忠誠度50、`sturdy` は既判明。剣士の強打（倍率1.7、CT3）と高いHP・守備で前衛になる一方、成長率と日給が経営上のトレードオフになる。

`bruno_glory` は3日目以降に忠誠度・評判を上げる代わりに、リナとの関係値を下げる場合がある。`bruno_knee` は派遣5回かつLv3で、負傷と疲労の数値を人生の話へ変える。

## 関係性

- リナ：初期関係値-14。武勇伝をからかわれ、送金の事実を知って関係が変わる。
- アルド：初期関係値+6。前衛の代わりを務めようとするアルドへ、前に立つことと責任を渡す。
- ミナ：固定初期値は未定義。ミナの手当てを受けるときだけ弱さを隠せない。
- ユウト：日給、施設、負傷、撤退を数値で管理するユウトに、数字の裏の身体を見せる。
- ミレイ：給与と記録を厳密に確認する相手。ガロ：酒場で過去の名声を聞く古い知人。

## 現行ポーズと将来候補

### 現行ゲーム内ポーズ

`neutral` は前衛・通常会話、`thoughtful` は撤退や膝の限界を考える場面、`happy` は若手へ役割を渡す場面と帰還に使う。

### 将来候補（現行アセット外）

武勇伝中の得意顔、撤退を告げる厳しい顔、膝をかばう無言、若手を教える柔らかな笑顔、装備を手入れする集中、負傷者を背負う苦悶、討伐後に肩の力を抜く安堵。追加する場合も、胸当て、盾、マントの赤を設定資料から変えない。
