# 『ギルドクエスト ― 見えちゃうギルドマスター ―』物語設計

## この文書の位置づけ

この文書は、ストーリーの目的、章の解放条件、ゲームシステムとの接続、キャラクター設計、今後のスチル要件をまとめる。数値や発火条件は、実装済みの `src/data/campaign-story.json`、`src/data/story-prologue.json`、`src/data/charevents.json`、`src/core/story.ts`、`src/core/charevents.ts` を基準にする。

本文では、現在ゲーム内で使うアセットと、今後追加する候補を分ける。現在は7人分の設定資料画像、各3ポーズ（`neutral` / `thoughtful` / `happy`）21点、5背景、2スチルが揃っている。既存5人（アルド、ミナ、リナ、ブルーノ、ミレイ）は `guild-dawn.webp` で確定した外見を個別資料へ固定し、ユウトとガロは個別資料を外見の正本とする。

## 作品の核

人物別の設計図: [ユウト](characters/yuto.md)、[アルド](characters/aldo.md)、[ミナ](characters/mina.md)、[リナ](characters/lina.md)、[ブルーノ](characters/bruno.md)、[ミレイ](characters/mirei.md)、[ガロ](characters/garo.md)。外見、配色、口調、弱点、成長、ゲーム上の役割を各ファイルで定義する。

現行本文の通読用資料は [全文](STORY-FULL.md) を参照する。序章・本編・個人イベント・噂・探索文はゲームのJSONから再生成し、未使用の旧稿 `story.json` は含めない。

主人公のユウト（プレイヤーが名前を変更可能）は、現代日本の人事部に勤める入社5年目の会社員だった。適性検査を読み、人を配属する仕事を終えた夜、終電を逃して異世界へ転移する。戦闘能力は持たないが、冒険者の能力・職業適性・性格・特性を本人にだけ読める。

ユウトは見えている数字をもとに配置を考えるだけだが、周囲には「才能を見抜く異国の賢者」「人を活かすギルドマスター」と誤解される。本人の慎重な提案、仲間の人生、街の期待が少しずつずれていき、ずれたままでも誰かが帰ってこられる場所を作ろうとする物語である。

舞台はハルトの街。灰竜が古い水路を塞ぎ、街の井戸が濁り始めている。市の査定が行われる30日目までに灰竜を討伐することが街の期待だが、物語の価値は討伐の成否だけに置かない。どの依頼を選び、誰を休ませ、誰の言葉を聞き、失敗した隊をどう迎えるかが、ギルドの形と仲間の変化を作る。

## 導入から最初の5日

`story-prologue.json` はゲーム開始時の紙芝居で、現代の人事部、転移、酒場店主ガロとの出会い、ガロや街の人を通した能力の発見、アルドとの会話と試射、ミレイとの設立相談、初期メンバーの登録までを54ページで見せる。仲間と操作は第一章から順に紹介し、期限の背景は6日目の章で説明する。`{name}` はプレイヤー名に置換される。プロローグの読了は、戦闘や報酬を発生させる処理ではなく、ゲームを開始するための導入である。

プロローグは54行、本編は14章71台詞、個人イベントは8件を収録する。通常行は背景・登場人物・ポーズ・位置・必要な効果音を明示し、重要な場面だけ `still` を指定する。ゲーム内の「物語とスチル」から設定資料と読了済みの章を再読できる。

本編の最初の5日間は、いきなり全システムを表示せず、ユウトの「見る・配置する・帰還を確認する」という職能を操作に置き換える。

| 日 | 解放と物語上の役割 | システム上の境界 |
|---|---|---|
| 1日目 | アルドの剣士から狩人への転職、薬草採取 | `c_aldo` を `ranger` に変えるまで派遣不可。初回派遣はアルド必須で1隊のみ。依頼は `q_herb` のみ。転職と初回派遣が済むまで日送り不可。 |
| 2日目 | 最初の帰還報告と森の仕事 | 森の依頼だけが対象。各依頼の評判条件は維持する。帰還結果、疲労、負傷、報酬をログで読む。 |
| 3日目 | 引き返す判断と回復薬 | 派遣方針と回復薬を解放。安全重視・標準・探索優先などの違いをログで学ぶ。 |
| 4日目 | 空いている椅子と新しい仲間 | 募集を解放。契約金（日給の4日分）、日給、定員を見て雇用する。 |
| 5日目 | 帰る場所を直す | 宿舎・治療所・訓練所を解放。強化費を払った後の日給まで考える。 |
| 6日目 | 研修終了と灰の便り | 財務を含む全機能と他エリアを解放。坑道・遺跡の依頼は、日数だけでなく各依頼の評判条件を満たす必要がある。 |

新規ゲームには最初の5日を支える初期支援金が1日90Gずつ記録される。これは固定メンバー4人の日給とギルド維持費を完全に無制限にするものではなく、最初の依頼を試し、負傷や募集を学ぶための運転資金である。各支給は台帳に残る。初回依頼は乱数で未達成になっても `introComplete` が進み、長期負傷でチュートリアルが止まらない。

## 4幕構成

### 第一幕：向いている場所、帰ってくる仕事

主題は「適性は人間そのものではない」。ユウトはアルドの剣士適性22、狩人適性92を見つける。アルドは三年間の剣の稽古を捨てることを恐れるが、弓を握ると手が迷わない。ミナは薬草採取を提案し、プレイヤーは初めて「適性を見て職業を変え、依頼に派遣する」というゲームの中心操作を行う。

`first_desk` は1日目に発生し、転職と薬草採取への派遣を案内する。`first_return` は2日目に発生し、依頼の成否と全員が帰還したかを別々に確認する視点を導入する。負傷者を休ませる、疲労を読む、帰還ログを残すことが第一幕の答えになる。

### 第二幕：引き返すための約束とギルドの形

主題は「強さは、進むことだけでは測れない」。3日目にブルーノが撤退の理由を語り、方針と回復薬が解放される。4日目にはリナの募集への軽口と、ブルーノの給与の現実が、仲間を増やすことを経営判断として見せる。5日目には薬草や包帯と依頼書の置き場所が足りないことをきっかけに、治療所・訓練所・宿舎のどれを先に整えるかを選ぶ。

`policy`、`recruit`、`facilities` の各章は、その日に解放される操作と同じ題材を扱う。プレイヤーに選択を説明するだけでなく、選択には日給、疲労、負傷、定員という帰結があることを台詞で示す。

### 第三幕：灰の便り、地図にない道

主題は「見える数字の外側に、生活がある」。6日目の `charter` で、鉱山から灰の混じった水が届き、灰竜が地下水路を塞いでいることが分かる。ブルーノは森、坑道、遺跡の順に準備するよう言い、リナは孤児院の井戸の濁りを語る。ユウトは街を救うという大きな言葉を、今日届ける水や一件の依頼へ分解する。

坑道の依頼を1件以上成功させると `mine` が読める。リナの過去の逃走経路を、ブルーノの赤いマントを目印にして「一人で覚える道」から「皆で帰る道」へ変える章である。日数6は解放可能日であり、評判条件と依頼成功履歴を満たさなければ章は発火しない。

第三幕では固定メンバーの個人イベントも進む。8日目以降のアルドは適性を成功の保証と誤解し、12日目以降のブルーノは前に立つ役割を若い世代へ渡す準備をし、16日目以降のミナは役に立ち続けることと休むことを分け始める。これらは共通の大筋を補強する条件付きエピソードであり、章を読んだだけで数値報酬を得る仕組みではない。

### 第四幕：数字にない答え、灯りを消さずに

主題は「最後の配置を、数字だけで決めない」。遺跡の依頼を成功させると `ruins` が発火し、水門を開けば街へ水を戻せる可能性が見える。アルドは最後の編成を数字だけで決めないよう求め、ブルーノは疲労・負傷・薬を確認した上で仲間を頼れと言う。リナは、帰った後に看板を塗り直す未来を口にする。

23日目以降の `eve` は、期限が迫っても怪我を増やしてまで出発しない判断を扱う。勝利条件だけを急ぐと、第一幕で学んだ「帰還を確認する仕事」と矛盾することを思い出させる章である。灰竜討伐依頼 `q_drake` は評判25で解放され、成功時に `finalCleared` が立つ。章の読了状況は戦力や評判を直接変更しない。

## 期限超過と討伐エンド

期限は30日。30日までに灰竜を討伐できなかった場合、31日目に `extension`「三十一枚目の依頼書」が開く。これはゲームオーバーではなく、査定が継続審査になり、街に必要とされる仕事を続けられる拡張エンドである。灰竜はまだ残り、プレイヤーは依頼、育成、施設、個人イベントを継続できる。

灰竜討伐に成功した場合は `homecoming`「帰ってくる人たち」が開く。水門が開き、街の井戸が澄み、アルド・ミナ・リナ・ブルーノが最初の薬草採取からの変化を振り返る。ユウトの結論は、見えた数字ではなく、見えないところを仲間が埋めたことにある。討伐エンド後も第一部完として依頼と記録は続けられる。

実装上、`src/core/story.ts` は以下の順で章を扱う。

1. `s.day < chapter.day` なら未解放。
2. `area` がある章は、該当エリアの依頼を1件以上成功していなければ未解放。
3. `ending: "clear"` は `finalCleared` のみで解放。
4. `ending: "extension"` は `finalCleared` でない状態で解放。
5. 討伐後は `ruins` と `eve` を保留章から除外し、討伐後の帰還を `homecoming` に集中させる。
6. `seenChapters` にない解放済み章を `pendingChapters` が返し、UIが1章ずつ表示する。既読処理は `finishChapter` が行い、再読しても報酬は発生しない。

### シーン演出とアセットの使い分け

主人公が現代の会社にいる間と転移直後は、`cast` に主人公を含めず、本人の発話行だけ `portrait` で台詞左の顔を指定する。服装差分は作らず、既存ポーズの顔だけを画面内で切り出す。ミレイからギルドの衣類と仕事道具を受け取る地の文の後に、今の立ち絵を表示する。

通常の台詞行は、5種類の背景（`guild` / `town` / `night` / `tavern` / `office`）と、左右・中央の最大3人の `cast` を組み合わせる。各人物は設定資料から派生した現行3ポーズを使い、`position`、話者、必要な `sfx`、`transition`、`effect` を行ごとに指定する。これにより同じ人物の髪型、衣装、小物が場面ごとに変わらない。

スチルは場面転換や結末など、画面全体を一枚で見せる必要がある重要行だけに使う。プロローグのギルド設立、討伐後の `homecoming` の水門と帰還が現行スチルの対象で、通常会話をスチルで埋めない。新しいCGを追加するときは、登場人物ごとの `reference.webp` を入力基準にして、既存スチルとの髪型・衣装・小物の差を確認する。

## 個人イベントと新章の役割

個人イベントは `src/data/charevents.json` に定義され、対象メンバーが存在し、待機中で、日数・派遣回数・レベル・職業・仲間の負傷条件を満たすと、日送りごとに最大1件発生する。発生済みIDは `seenCharEvents` に保存され、同じイベントは再発生しない。効果は忠誠度、評判、関係値、特性の判明であり、章の既読状態とは別管理である。

| キャラクター | 実装済み個人イベント | 新章で補うこと |
|---|---|---|
| アルド | `aldo_bow`（ranger・2日目）、`aldo_caution`（派遣4回） | `aldo_trust` で「向いている」と「必ず成功する」を分離する。 |
| ミナ | `mina_herb`（派遣2回）、`mina_worry`（仲間負傷） | `mina` で、薬を渡す人にも休む権利があると描く。 |
| リナ | `lina_lost`（派遣3回）、`lina_money`（5日目） | `mine` で過去の逃走経路を、共有できる帰還路へ変える。 |
| ブルーノ | `bruno_glory`（3日目）、`bruno_knee`（派遣5回・Lv3） | `bruno` で前に立つ役割を次世代へ渡す。 |
| ミレイ | 現在は固有個人イベントなし | 受付・記録・解放条件の案内役として全章をつなぐ。 |
| ガロ | 現在は固有個人イベントなし | プロローグの生活基盤と、期限超過後も街が続く感覚を支える。 |
| ユウト | 現在は固有個人イベントなし | 主人公名置換と心中の短文で、数字と人のずれを示す。 |

## アートの現状と制作境界

現行アセットは、人物の外見を固定する設定資料、通常場面を構成する背景・立ち絵、重要行のスチルに分かれる。

- 7人の設定資料：[aldo](../public/art/characters/aldo/reference.webp)、[bruno](../public/art/characters/bruno/reference.webp)、[garo](../public/art/characters/garo/reference.webp)、[lina](../public/art/characters/lina/reference.webp)、[mina](../public/art/characters/mina/reference.webp)、[mirei](../public/art/characters/mirei/reference.webp)、[yuto](../public/art/characters/yuto/reference.webp)。各資料には正面・側面・背面、表情、小物、配色が含まれる。
- 現行立ち絵は各人物の `neutral` / `thoughtful` / `happy` の3ポーズ。人物ごとのリンクと固定事項は [キャラクター設計図](characters/) にまとめる。
- 背景は `public/art/backgrounds/guild.webp`、`town.webp`、`night.webp`、`tavern.webp`、`office.webp` の5点。
- `public/art/guild-dawn.webp` はアルド、ミナ、リナ、ブルーノ、ミレイの5人集合で、仕事が始まるギルドの基準スチル・章サムネイル。`public/art/ruins-vow.webp` は水門を取り戻した討伐後の帰還スチルで、`homecoming` の重要行だけが参照する。

現行3ポーズ以外は、必要な場面が決まったときに追加する候補である。候補には、負傷、怒り、照れ、休息、帰還確認などの表情、職業変更に伴う武器・衣装差分、坑道・薬草茶・看板・期限超過などの個別スチルを含める。ただし追加時も、先に各人物の `reference.webp` を基準にし、既存の髪型、衣装、配色、小物と差分を確認する。
