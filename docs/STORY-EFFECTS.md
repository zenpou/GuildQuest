# ストーリーの画面演出と立ち絵モーション

ゲーム本編・物語の再読・`story.html` は同じストーリープレイヤーを使います。演出は台詞に明示指定し、文中の感嘆符や話者交代だけでは自動再生しません。

## 台本での指定

各行は従来どおり、その行だけで背景・立ち絵・ポーズ・位置を再現できる完全な舞台情報を持ちます。

| 指定箇所 | 値 | 用途 |
| --- | --- | --- |
| `transition` | `cut` | 即時切り替え。省略時も同じ |
| `transition` | `fade` | 前の場面からフェードで切り替え |
| `transition` | `wipe` | 横方向のワイプで切り替え |
| `transition` | `blackout` | 暗転を挟む場面・時間の切り替え |
| `effect` | `shake` | 背景・立ち絵・スチルを含む舞台の揺れ |
| `effect` | `flash` | 短い光の演出 |
| `effect` | `impact` | 衝撃の揺れと光を組み合わせる |
| `cast[].motion` | `enter-left` / `enter-right` | 左／右から定位置へ登場 |
| `cast[].motion` | `jump` | 驚きや喜びで跳ねる |
| `cast[].motion` | `nod` | うなずき・会釈 |
| `cast[].motion` | `shake` | 首振りに相当する左右の動き |
| `cast[].motion` | `recoil` | びくっと身を引く反応 |
| `cast[].motionAt` | 本文中の語句 | その語句が全文表示された瞬間に立ち絵を動かす |
| `effectAt` / `sfxAt` | 本文中の語句 | 画面効果／効果音を文章の該当箇所に合わせる |

```json
{
  "speaker": "リナ",
  "text": "うるさい、おじさん！",
  "background": "guild",
  "transition": "cut",
  "cast": [
    { "character": "lina", "pose": "thoughtful", "position": "left", "motion": "shake", "motionAt": "うるさい" },
    { "character": "bruno", "pose": "neutral", "position": "right" }
  ]
}
```

これは指定形式の例です。既存台本の位置とポーズを維持して `motion` を足してください。複数人の動きは独立し、画面切り替えや画面効果とも併用できます。動きの指定はその行限りで、終わると通常の立ち位置に戻ります。`portrait` の顔画像や、`still` で隠れている立ち絵には適用しません。

`motionAt` などは本文中の完全一致する語句を使います。指定した語句が見つからない場合は、その演出を再生しません。主人公名の `{name}` は本文と同じように置換します。省略すると従来どおり行の表示開始時に再生しますが、現行の台本の立ち絵モーションはすべて語句を指定しています。

動きは動作や反応に対応させます。お礼のお辞儀を心配事の説明中に先出ししたり、弓を射る本人を被弾したようにのけぞらせたりしません。会話だけの場面には画面全体の衝撃や閃光を足さず、人物の反応だけを使います。同じ場面で続けて映る人物は左右位置を維持し、場面転換の際に構図を変えます。

## 操作との関係

- 初回表示と次の行への移動で演出の準備をし、指定語句が表示された時点で一度だけ再生します。前へ戻ると、その行の完成した舞台を即時表示します。
- 全文表示でまだ表示していない指定語句に達した場合、その演出を一度だけ再生します。再生済みの演出は繰り返しません。会話履歴や台詞の表示切り替えでも再開しません。
- 連続で次へ進むと、それまでの演出を破棄して最新の行へ移ります。スキップ・終了時も破棄します。
- ツールバーの「演出ON／OFF」で切り替えられます。OFFにすると動作中の演出も終了します。設定はこのブラウザに保存され、別の章や次回起動時にも引き継ぎます。
- OSの「視差効果を減らす」設定（`prefers-reduced-motion`）を優先し、揺れ・光・場面切り替え・立ち絵の動きを抑止します。
- OFFやOS設定で抑止した行の未再生モーションは、同じ行の途中でONに戻しても再開しません。次の行から設定を反映します。

## 台詞と演出の対応例

| 場面 | 対応 |
| --- | --- |
| ユウトの就任挨拶 | 冒頭の「落ち着かない」では動かず、「よろしくお願いします」でお辞儀 |
| アルドの弓の練習 | 射手ののけぞりと画面の衝撃を外し、「弓を引いた」で効果音 |
| アルドの喜び | 「当たった」で小さく跳ねる |
| ガロの適性が見える | 「薄い文字が浮かんだ」で弱い光と効果音 |
| ミナの謝罪 | 状況説明中には動かず、「ごめんなさい」でお辞儀 |
| リナの照れ隠し | リナだけが「うるさい」で小さく左右に動く。相手や背景は揺らさない |

`npm run test:alignment` では上記の実際の文章について、該当語句の直前には静止し、表示時点で動くこと、画面転換の終了が後から始まった動きを途中で消さないことをChromeで確認します。証跡は `artifacts/story-alignment/` に保存します。

## 台本への組み込みと検証

プロローグの転移・場面移動・弓の練習・仲間の登場、本編の喜びや相づち、個人エピソードの慌てた反応に指定済みです。本文・報酬・解放条件・セーブ形式は変更しません。

`npm run test:effects` は実際のChromeで6種類の立ち絵モーション、3種類の場面切り替え、3種類の画面効果、同時再生、連打、戻る、OFF、OS設定変更、破棄を検証します。PC・スマホ・小画面・横持ちで確認し、途中の画面と結果JSONを `artifacts/story-effects/` へ保存します。製品ビルドへの統合は `npm run build` の後、既存の `npm run test:story` で確認します。

初回実装時は、更新後のプロローグ77行を含むビルドと85件の単体テスト、Chromeの4画面サイズでの再生テストに成功しました。ただし、その検証は主に演出の動作確認であり、文章のどの時点で動くか、反応が内容に合うかの確認が不足していました。

2026-10-03の対応修正後は、ビルドと95件の単体テスト、`test:effects` と製品版の `test:story` が成功しました。後者2つはChromeの1440×1000、390×844、320×568、844×390で検証し、ブラウザ例外は0件です。さらに `test:alignment` では1280×900と390×844で、挨拶直前の静止、挨拶時のお辞儀、能力発見の光と音、射手がのけぞらないこと、文字送りと全文表示による発火、OFF・戻る・連打時の破棄を確認しました。本文とゲーム進行の定義は変更していません。再生動画は `artifacts/story-alignment/dialogue-motion.webm`、結果は同フォルダの `check.json` にあります。実機スマートフォンでは未確認です。
