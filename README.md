# ギルドクエスト 〜見えちゃうギルドマスター〜

才能の見える主人公が、冒険者の職業と編成を考える物語付きギルド経営ゲーム。Web/PWA版の第一部です。

## 起動

Node.js 22.12以降とnpmを使用します。

```sh
npm ci
npm run dev
```

開発画面は `http://localhost:5173`。PWA・オフライン動作は製品ビルドで確認します。

```sh
npm run build
npm run preview
```

製品プレビューは `http://127.0.0.1:4173`。公開用ファイルは `dist/` にまとまります。

## 序盤の遊び方

1. 名前を決め、プロローグと最初の章を読む。スキップしても章は記録に残る。
2. 「冒険者」でアルドの適性を見て、剣士から狩人に転職する。
3. 「派遣」で薬草採取を選び、アルドとミナを編成して出発させる。他の仲間も同行可能。
4. 「次の日へ」で帰還を確認。成否、疲労、怪我、冒険ログを見る。
5. 3日目に方針と回復薬、4日目に募集、5日目に施設、6日目に財務と他エリアが解放される。依頼ごとの評判条件は残る。

帰還報告と冒険ログの「帰還のひとこと」では、参加メンバー全員が結果に応じて話します。固定メンバー4人には専用台詞、募集した冒険者には性格別の台詞があり、成功・未達成・撤退・全滅で変わります。台詞は記録に保存され、読み返しても変わりません。追加前の冒険記録は従来の表示を保ちます。

最初の5日間は1日90Gの市の支援金があります。初回依頼が失敗しても進行し、負傷は最大1日。資金が赤字でも薬なしの派遣はできます。

30日以内の灰竜討伐を目指します。期限超過後も続行でき、後から討伐エンドに到達できます。54ページのプロローグ、14章71台詞、個人イベント8件、5背景、7人分の設定資料画像、各3ポーズの現行立ち絵21点、ストーリースチル2点を収録。通常行は背景・立ち絵・ポーズ・台詞・効果音を組み合わせ、重要行だけスチルに切り替えます。章は日数や探索成功、討伐に応じて開き、ホームの「物語とスチル」で再読できます。

## 画面と保存

PC・スマホとも「管理卓」を標準UIとして開始します。通常画面には比較用の切替ボタンを表示しません。旧案は検討用の `?ui=desk|hall|pocket` から表示でき、同じCoreとセーブを使います。

ブラウザのlocalStorageへ操作ごとに自動保存します。既存のセーブは維持し、旧版セーブは既存機能をロックしない互換モードで読み込みます。新しい序盤は「最初から」で始まります（確認後にセーブ上書き）。別端末への自動同期、セーブのクラウド保存はありません。

## PWA

HTTPSのWebサイトへ `dist/` 全体を配置すると、対応ブラウザからインストールできます。初回のオンライン読み込みと「オフラインでも遊べます」の表示を確認すれば、次から通信なしでも本編・ストーリー・画像を利用できます。更新は「更新して再起動」で適用し、セーブを保持します。詳しくは [Web配布と各端末への展開](docs/PLATFORMS.md)。

## 検証コマンド

```sh
npm test
npm run test:story
npm run test:effects
npm run build
npm run test:browser
npm run test:returns
npm run sim -- 100
npm run sim:styles
```

`sim:styles` は遊び方(雇用して2隊/初期4人だけ/施設を建てない など)ごとに30日を自動で進め、期限内クリア率・所持金の推移・灰竜への初挑戦日を比べます。

ブラウザ検証にはインストール済みGoogle Chromeを使用します。`test:browser` は専用のローカルサーバーと新規ブラウザプロファイルでPC・スマホ幅、初日操作、6日目、保存、offline、PWA更新、旧セーブ、両エンドを検証し、`artifacts/` に画面とJSONを出力します。通常のブラウザセーブには触れません。

`src/core/` はDOM非依存、`src/data/` は定義・台詞、`src/ui/` は画面、`public/` は配布画像とPWAアイコンです。`scripts/pwa-plugin.ts` がビルド成果物をハッシュ化してService Workerを生成します。`story.html` は現行プロローグ54行をゲームと同じストーリープレイヤーで確認できるプレビューです。セーブは変更しません。

物語の推敲済み全文は [STORY-FULL.md](docs/STORY-FULL.md) または `/story-manuscript.html` で読めます。`node scripts/export-story.cjs` で現行の台本から再生成します。
